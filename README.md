# Snake
One of my first real games written by myself. It is quite different compared to the typical algorithms used to program snake. 
With a linked list and invisible boxes, which directs the whole body of the snake if turned, I made a functional game that has a moving and growing (if the fruit is eaten) snake, a counter that counts how many points you've gotten and of course the snake can die.
To start the game you need to install pygame beforehand.
